---
title: Choose a new box's disk
surface: lab
category: new
date: 2026-10-29
---
New project's new box now has a Disk (GB), from 50 to 300 (120 by default), and `termag box create --disk <GB>` sets it from the command line. A repository can ask for one with `resources.diskGiB` in its `.termag/environment.json`.
